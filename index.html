The World Wide Web

From Simple Wiki, the free encyclopedia

The World Wide Web is an information system that allows documents and other resources to be connected through hyperlinks. It is one of the most recognizable uses of the Internet.

This project demonstrates semantic HTML elements such as <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>.

History

The Web was developed as a way to make information easier to share and connect. Its foundation relies on technologies including HTML, URLs, and HTTP.

“The Web is an information space in which the items of interest are identified by global identifiers.”

Important technologies

  • HTML — document structure.
  • CSS — presentation and layout.
  • JavaScript — behavior and interaction.
